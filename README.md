# Política de Privacidade – Inventory Control

Última atualização: 10 de novembro de 2026

Esta Política de Privacidade descreve como o aplicativo Inventory Control ("Aplicativo") trata os dados de seus usuários ("Usuários"). O Aplicativo é uma ferramenta de uso privado e restrito, destinada exclusivamente à realização e gestão de contagens de inventário operacional.

---

### 1. Dados Coletados

Para viabilizar o controle de acesso e o registro das contagens, o Aplicativo pode coletar:
- **Dados de Identificação e Acesso:** Nome completo, endereço de e-mail e credenciais de login fornecidas ou cadastradas pelo administrador para autorização de uso.
- **Registros Operacionais de Inventário:** Identificação dos itens contados, quantidades, horários das leituras/contagens e associação do usuário responsável pelo registro.
- **Dados Técnicos de Diagnóstico:** Informações básicas do dispositivo (modelo, versão do sistema operacional e relatórios técnicos de falhas), coletadas exclusivamente para correção de erros e estabilidade.

*Nota: O Aplicativo NÃO rastreia geolocalização em segundo plano, não acessa contatos, fotos pessoais ou arquivos fora do escopo estrito de funcionamento da contagem.*

---

### 2. Finalidade do Tratamento dos Dados

Os dados coletados são utilizados estritamente para:
- Autenticação e validação de permissões de acesso ao sistema;
- Atribuição de responsabilidade pelas contagens e conferências de estoque realizadas;
- Sincronização e armazenamento seguro dos dados operacionais;
- Suporte técnico e garantia de estabilidade do Aplicativo.

Os dados não são comercializados, alugados nem utilizados para fins de marketing, publicidade comportamental ou criação de perfis de consumo.

---

### 3. Compartilhamento de Dados

Não compartilhamos informações pessoais ou dados de inventário com terceiros, exceto:
- Provedores de infraestrutura de nuvem e banco de dados contratados exclusivamente para hospedagem e funcionamento técnico do Aplicativo, sob estritos deveres de sigilo;
- Para cumprimento de obrigações legais ou ordens de autoridades competentes.

---

### 4. Armazenamento e Segurança

Adotamos medidas técnicas e administrativas razoáveis para proteger os dados contra acessos não autorizados, perdas ou alterações:
- O tráfego de dados entre o Aplicativo e os servidores é protegido por criptografia (HTTPS/TLS);
- O acesso às informações de inventário é restrito aos usuários expressamente autorizados pelo administrador.

---

### 5. Exclusão de Contas e Retenção de Dados

Os dados cadastrais e os registros de inventário permanecem armazenados enquanto a conta do usuário estiver ativa e conforme necessário para as rotinas operacionais e obrigações legais.

O Usuário ou administrador pode solicitar a revogação de acessos ou a exclusão dos dados pessoais a qualquer momento pelo e-mail de contato indicado abaixo.
